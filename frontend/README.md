# Sentinel · 数据异常监控平台前端

一套完整的数据异常监控平台前端 UI，覆盖**数据源管理、数据集管理、异常规则配置、异常记录展示**四大核心模块。纯前端实现，所有数据为内存模拟数据，所有交互（增删改查、测试连接、SQL 执行、规则触发、状态流转）均在前端完成，无需后端。

## 设计理念

**Refined Industrial Dashboard** — 面向数据工程师的专业监控平台。

| 维度 | 选择 |
| --- | --- |
| 色调 | 暖纸白底 `#FAFAF7` + 深墨字 `#0A0A0A` + 炭灰侧栏 `#14141A` |
| 主色 | 靛蓝 `#4F46E5`（品牌/操作） |
| 强调色 | 珊瑚 `#F97066`（异常/告警语义） |
| 字体 | Sora（标题）· Manrope（正文）· JetBrains Mono（代码/数据） |
| 布局 | 左侧固定导航栏 + 右侧内容区，无边框卡片 + 柔和阴影 |
| 动效 | 渐入式 staggered reveal，悬停过渡，无花哨装饰动画 |

```
    ├── icons.js                # 集中化 SVG 图标库（70+ 图标）
    ├── data.js                 # 内存数据存储 + 状态管理（CRUD API）
    ├── components.js           # 可复用组件：Modal / Drawer / Toast / Badge / 表单等

```

## 快速开始

无需构建步骤，纯静态资源。任选其一：

```powershell
# 方式一：Python 内置服务器
cd frontend
python -m http.server 8765
# 浏览器打开 http://localhost:8765/index.html

# 方式二：Node http-server
npx http-server frontend -p 8765

# 方式三：直接打开（部分浏览器对 file:// 下的字体加载有限制，推荐使用服务器）
start frontend/index.html
```

默认进入「异常记录」页（系统最高优先级功能）。

## 功能模块

### 1. 异常记录（默认首页）

系统检测到的所有数据异常事件，是用户进入系统后的默认落点。

- **状态卡片**：未处理 / 处理中 / 已解决 / 严重异常，突出待办与紧急程度
- **状态标签页**：全部 / 未处理 / 处理中 / 已解决，带实时计数
- **列表**：异常 ID、严重程度（含 severity meter 可视化）、触发规则、异常字段与值（实际 vs 预期）、状态、发生时间、处理人
- **筛选**：搜索、严重程度、规则；列排序（严重程度、发生时间）
- **详情抽屉**：基本信息、异常数据对比、完整数据明细、处理时间线
- **状态流转**：单条快速更新（弹窗选择）+ 批量更新（多选后批量标记）
- **导出**：模拟导出当前筛选结果或选中记录为 CSV

### 2. 异常规则

数据质量检测规则与通知策略配置。

- **状态卡片**：规则总数、累计异常、触发规则、已停用
- **列表**：规则名称、关联数据集、严重程度、调度频率、最近执行、异常次数；行内启用/停用开关；触发过的规则行高亮
- **新建/编辑表单**（分区块）：
  - 基本信息：名称、严重程度（4 级）、描述
  - 关联数据集：选择数据集后自动加载字段
  - 异常条件：可视化条件构建器，支持 11 种操作符（大于/小于/介于/为空/超过基线倍数等）+ AND/OR 逻辑组合 + 多条件增删
  - 调度规则：频率（分/时/天）+ 间隔 + 执行时间 + 起止日期，带 cron 风格预览
  - 飞书通知：手动输入 open_id/user_id（标签输入）或从数据集字段选择 ID 字段
- **模拟执行**：表单内可模拟执行预览触发结果

### 3. 数据集

基于 SQL 的监控数据视图。

- **状态卡片**：数据集总数、关联数据源、总数据行数、今日更新
- **列表**：名称、描述、关联数据源、字段（带类型，超过 3 个折叠为 +N）、行数、更新时间
- **查询预览抽屉**：
  - SQL 编辑器：深色主题、行号、语法高亮（关键字/函数/字符串/数字/注释分色）、Tab 缩进、Ctrl+Enter 运行
  - 校验：实时检测 SELECT/FROM 缺失、括号匹配、LIMIT 建议等
  - 格式化：一键重新排版 SQL
  - 结果预览：模拟执行返回数据表，显示行数、耗时，支持导出
- **新建/编辑**：表单内嵌 SQL 编辑器，运行后自动解析字段

### 4. 数据源

MySQL 与 StarRocks 连接管理。

- **状态卡片**：总数、在线、异常、离线
- **列表**：名称、类型徽章（MySQL/StarRocks 配色）、连接信息（host:port + database）、状态指示灯（在线/异常/离线 + 脉冲动画）、创建时间、最近检测
- **测试连接**：行内一键测试，模拟异步检测，更新状态与最近检测时间
- **新建/编辑表单**：
  - 类型选择：MySQL / StarRocks 卡片式单选（带图标与默认端口）
  - 连接信息：主机、端口（按类型自动填充默认值）、数据库、用户名、密码（可显隐切换）、SSL 开关
  - 表单内测试连接

### 5. 总览

平台运行状态全景仪表盘。

- 异常趋势 14 天柱状图（今日高亮）
- 系统健康度评分（含可用性、覆盖率、响应率等指标）
- 最近异常列表（可跳转详情）
- 触发最多的规则排行

## UI/UX 设计要点

### 视觉
- **无边框设计**：通过留白与阴影区分功能区，避免视觉噪音
- **配色克制**：3 主色（纸白/墨黑/炭灰）+ 1 主操作色（靛蓝）+ 1 告警强调色（珊瑚）+ 语义状态色
- **扁平化**：去除过度阴影与渐变，仅保留必要的层次阴影

### 信息架构
- 顶部展示模块标题 + 简要描述 + 主操作按钮
- 卡片式布局区分功能区块
- 次要信息（帮助文本、说明）弱化样式
- 列表默认展示最重要列，次要信息折叠

### 交互
- 核心操作不超过 3 步
- 所有可交互元素提供悬停/点击/禁用状态反馈
- 完整 Loading / Empty / Error 状态展示
- 批量操作（异常记录多选批量更新）
- 键盘快捷键（SQL 编辑器 Ctrl+Enter 运行、Tab 缩进、Esc 关闭模态）

### 响应式
- 桌面（>860px）：完整侧栏 + 内容区
- 平板（≤860px）：侧栏抽屉化，顶栏搜索隐藏
- 移动（≤640px）：单列堆叠，按钮全宽

### 可访问性
- 语义化 HTML（`nav` / `main` / `heading` / `aria-label`）
- 键盘可达（Tab/Enter/Space/Esc）
- `prefers-reduced-motion` 媒体查询禁用动画
- 焦点可见（focus ring）

## 技术栈

- **HTML5 + CSS3 + 原生 JavaScript**（无框架、无构建步骤，最大可移植性）
- CSS 自定义属性（CSS Variables）统一设计令牌
- IIFE 模块封装，全局命名空间 `Store` / `UI` / `Icon` / `App` + 各模块对象
- Google Fonts CDN 加载 Sora / Manrope / JetBrains Mono

## 模拟数据说明

所有数据位于 [scripts/data.js](scripts/data.js)，通过 `window.Store` 暴露 CRUD API：

- 4 个数据源（含在线/异常/离线状态）
- 4 个数据集（含完整字段定义与示例 SQL）
- 4 条异常规则（含多种条件、调度、通知配置）
- 12 条异常记录（覆盖 4 种严重程度、3 种处理状态）

所有增删改操作直接修改内存数据并触发 UI 重渲染。刷新页面将重置为初始数据。

## 浏览器兼容

Chrome / Edge / Firefox / Safari 现代版本。需支持 CSS 自定义属性、CSS Grid、backdrop-filter。

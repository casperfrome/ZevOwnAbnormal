> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore condition rendering and editing interactions when an existing anomaly rule is opened.

**Architecture:** Keep the existing native-JavaScript modal and state model. Reorder form initialization so all condition-rendering dependencies and event handlers exist before an existing dataset triggers its initial refresh, then harden non-submit buttons with explicit button types.

**Tech Stack:** Native browser JavaScript, Node.js built-in test runner, Playwright Chromium.

- Add no runtime dependencies or unrelated refactors.
